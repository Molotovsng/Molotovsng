# Никита Чепкасов

Работаю менеджером по аналитике, развитию и проверкам в розничной компании. Занимаюсь оценкой рисков при найме и автоматизирую процессы службы безопасности.

## Что я сделал

**[Бот для обращений в службу безопасности](https://github.com/Molotovsng/max-support-bot).** Разработал и запустил в MAX единый канал для сотрудников, контрагентов и частных лиц. Бот распределяет обращения по пяти направлениям и возвращает ответы специалистов в личный диалог. Провёл бота через модерацию, подготовил запуск и журнал событий без содержимого переписки. В репозитории доступна обезличенная версия.

**Проверка кандидатов.** Участвую в интеграции личного кабинета с сервисом проверки. Согласовываю с разработчиками, как передавать заявки и возвращать результаты в личный кабинет. Для однозначных результатов предусмотрен автоматический статус. При риске или недостатке данных карточку проверяет специалист. Моя часть проекта — требования, логика статусов и сценарии проверки.

**[Библиотека на Python и SQLite](https://github.com/Molotovsng/library-coursework).** В курсовом проекте спроектировал базу фонда, читателей и выдач, сделал настольное приложение и SQL-отчёты. Ограничения в базе предотвращают повторную выдачу занятого экземпляра и контролируют лимит активных выдач на читателя.

## Навыки

- **Python и интеграции** — асинхронная обработка событий, HTTP API, HTTPX, FastAPI, long polling и webhook. Пишу тесты с подменой внешнего API, готовлю сборки для Windows через PyInstaller.
- **Данные** — SQL и SQLite, реляционные схемы, транзакции, ограничения и триггеры. Готовлю отчёты и работаю с табличными выгрузками.
- **Экономическая безопасность и аналитика** — проверка кандидатов, анализ факторов риска, разработка чек-листов и правил принятия решений. Перевожу эти правила в требования к автоматизации и сценарии тестирования.
